# Codex · Homeoffice.hu következő fejlesztési feladatok

Olvasd el a `README.md`-t, az `AGENTS.md`-t és az aktuális `index.html`-t. Ez a korábbi fiktív katalógus helyett már 11 valódi Alibaba-terméket mutat be eredeti beszállítói kép URL-ekkel és ellenőrizhető linkekkel.

## Priorizált feladat
1. Futtasd az `npm test`-et, és nézd meg a publikus GitHub Pages oldalt desktopon és mobilon.
2. Ellenőrizd a termékfotók tényleges betöltését, külalakját és mobilméretét; ha CDN-blokkolás van, **ne** generálj a termék helyett hamis fotót. Forráshelyes, jogosított képmegoldást készíts.
3. Vizsgáld a keresés, szűrés, termékmodál, kedvencek és demókosár működését. Javítsd a hibákat a megjelenés megtartásával.
4. Finomítsd a prémium vizuális részleteket: nagyvonalú fehér terek, tiszta tipográfia, erős termékképek, finom animációk és gyors mobilélmény. Külön márka, nem Apple-imitáció.
5. A következő fejlesztési körhöz készíts javaslatot a tényleges beszállítói feltételek, fotójogok, árak és készletkezelés kezelésére.

**Korlát:** checkout, éles fizetés, rendelés, ügyféladat-kezelés ne legyen bekapcsolva külön engedély nélkül. Nyiss PR-t a fejlesztésekkel, és írd le a böngészőteszt eredményét.
