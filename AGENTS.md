# Homeoffice Studio

Hungarian, non-commercial product-reference storefront. The authorized reconstruction contains 28 distinct real manufacturer references across chairs, desks, stands, docks, devices, networking, accessories and lighting. Never imply secured suppliers, independent quality tests, stock, brand affiliation or availability to purchase.

- Independent Homeoffice identity. Black, white and gray UI with natural wood photography. No Apple logos, invented reviews, prices, warranty or health promises.
- Product cards contain only the original photograph and short presentation alias. Original maker/model/source and factual descriptions belong in the accessible detail dialog.
- Data is in catalog.json. Keep HTML, CSS, refinements and application code separate. No framework migration is needed.
- Build retrieves exact source photographs and creates self-hosted WebP images with consistent neutral padding. Never alter product geometry or replace photos with invented illustrations. Rights remain with the original owners; commercial reuse requires authorization.
- No payments, real orders, accounts, analytics or personal-data collection. Favorites and demo cart use localStorage only.
- Run npm test, npm run build and npm run qa. Inspect screenshots, not just green tests. The single Pages workflow gates publication on photo validity and desktop/mobile interaction checks, then tests the exact deployed commit at the public URL.
- Keep responsive layouts at 1440/768/390/320px, keyboard focus restoration, native dialog Escape, visible mobile close control, reduced motion, accent-insensitive search, truthful attribution and no horizontal overflow.
- QA artifacts homeoffice-visual-qa and homeoffice-live-qa include screenshots and JSON results. Do not commit temporary screenshots or debug output.
